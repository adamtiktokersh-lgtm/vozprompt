# VOZPROMPT

Aplicativo independente para transformar ideias escritas ou faladas e imagens de referência em prompts estruturados.

## Fluxo de trabalho

- GitHub: fonte oficial do código.
- Lovable: somente visualização/homologação após sincronização confirmada.
- Desenvolver em branches e pull requests; nenhuma publicação ou merge automático.
- Nunca salvar chaves de API ou arquivos pessoais no repositório.

## Estado

Implementação inicial em desenvolvimento. A análise real de imagens e a transcrição de áudio por IA dependem de serviços seguros de backend. Recursos de demonstração devem ser explicitamente identificados.
